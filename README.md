# Portfólio pessoal - Bernardo Pimentel

Site estático para GitHub Pages que apresenta meu perfil como estudante de Ciência da Computação no UniCEUB Centro Universitário de Brasília.

O portfólio destaca minha base em Python, meus estudos em Java e JavaScript, formação acadêmica, habilidades, idiomas, contato e projetos públicos do GitHub, incluindo [equitrack](https://github.com/Bernardopmtld/equitrack).

## Seções

- Perfil pessoal
- Resumo profissional
- Formação acadêmica
- Tecnologias em estudo
- Hard skills, soft skills e idiomas
- Projetos em destaque
- Contato por email, telefone e GitHub

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript com Fetch API
- GitHub REST API

## Publicação

O site pode ser publicado diretamente pelo GitHub Pages a partir da branch `main`, usando a pasta raiz do repositório.
